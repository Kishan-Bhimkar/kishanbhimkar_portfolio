# Kishan Bhimkar — Portfolio Website

A responsive, professional light-theme portfolio for Electronics Engineering — VLSI Design & Technology.

## Files
- `index.html` — portfolio content and sections
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and current-year footer
- `assets/images/profile.jpg` — profile photograph
- `assets/documents/resume.pdf` — resume linked from the homepage

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Keep the `assets` folder structure unchanged.
3. Commit the files to the `main` branch.
4. In GitHub, open **Settings → Pages** and ensure the source is set to deploy from the `main` branch and `/ (root)`.

## Update later
Replace `assets/images/profile.jpg` to change the profile photo, keeping the same filename. Replace `assets/documents/resume.pdf` to update the resume, keeping the same filename.
