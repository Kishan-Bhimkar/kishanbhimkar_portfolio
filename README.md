# Personal Portfolio Website

A responsive dark-themed portfolio starter for GitHub Pages.

## 1. Personalise before publishing

Open `index.html` and replace:
- `Your Name` with your full name.
- `YOUR_GITHUB_USERNAME` with your GitHub username.
- `YOUR_LINKEDIN` with your LinkedIn profile username/path.
- `YOUR_EMAIL@example.com` with your professional email address.
- Update the education, skills, project descriptions, fellowship and certification details so they accurately reflect your experience.

## 2. Add your resume

Place your PDF resume at:

`assets/documents/resume.pdf`

If you do not want to publish your resume yet, remove the “View resume” link from `index.html`.

## 3. Preview locally

Double-click `index.html` to open it in a browser. For a better local preview, open the folder in VS Code and use the Live Server extension.

## 4. Publish with GitHub Pages

1. Create a **public** GitHub repository named exactly `YOUR_GITHUB_USERNAME.github.io`.
2. Upload the contents of this folder (upload `index.html`, `style.css`, `script.js`, `README.md`, and `assets`—not the outer folder itself).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait a few minutes and visit `https://YOUR_GITHUB_USERNAME.github.io/`.

## 5. Before sharing the link

- Test every social and project link.
- Check the website on mobile.
- Do not publish private data, API keys, passwords, or confidential project files.
- Only list skills and project results you can explain in an interview.
