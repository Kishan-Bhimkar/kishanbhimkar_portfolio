## Publish to your existing GitHub Pages repository
1. Extract this ZIP.
2. Open your existing repository: `kishanbhimkar_portfolio`.
3. Upload/replace the files and the `assets` folder in the repository root.
4. Commit the changes to the `main` branch.
5. Wait for GitHub Pages to deploy, then refresh:
   https://kishan-bhimkar.github.io/kishanbhimkar_portfolio/

Do not rename the repository; this portfolio is intended for the existing repository and URL.
